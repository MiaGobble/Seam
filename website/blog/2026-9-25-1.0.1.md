v1.0.1 fixes many memory-related issues, both bugs and design problems.

<!-- truncate -->

Here is a complete list of changes:
* Improved readability of style sheet files
* Improved typing in style sheet methods
* Added and implemented Pesde
* Published Seam to Pesde
* Updated tooling
* Fixed memory leak caused by inner scopes
* Fixed memory leak with `OnEvent`
* Fixed memory leak with `OnAttributeChanged`
* Improved cleanup behavior across Seam
* Fixed cleanup on style sheets

Most important is the fix to memory leaks with inner scopes. They should now be considered the most reliable way to manage leaks within a scope.

Style sheets also needed some fixing up! See the issue I fixed here: https://github.com/MiaGobble/Seam/issues/45

While they might not be happening to you yet, memory leaks are no fun to find later down the line, so make sure to update Seam as soon as possible!
