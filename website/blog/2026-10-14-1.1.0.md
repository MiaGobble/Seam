v1.1.0 is a massive update composed of 117 commits that improves Seam as a product and as a development project.

<!-- truncate -->

Changes to how you use Seam:
* Added property and class typechecking/autofill using the new solver for `New()`
* Added `Scope:CleanInnerScopes()`
* Fixed bug with StateManager when bucket instance destroys early
* Fixed missing, outdated, and misleading parts of docs

Changes behind the scenes:
* Restructured constructors in Seam behind-the-scenes for improved readability and conciseness, cutting each constructor by an average of 16% lines of code.
* Added CI with unit tests to ensure broken code doesn't get shipped.
* Swapped from Trove to Bucket for backend cleanup
* Updated backend signal module to fix bug
* Replaced backend Oklab module for more readable one from Praxis
* Converted codebase to use Oxomo Games' coding conventions
* Moved docs to Seam repository to unify everything (this also means docs are now open-source)

The most outstanding change here is the autofill and typechecking capabilities added to `New`. Huge thanks to the contributors that made this possible! This works with building new instances or hydrating existing ones.

You'll notice, though, a lot of changes are behind the scenes. Much of what was done improved readability and stability.

The biggest change is to how constructors are written. Not only is it much easier to read, but the amount of code to write a constructor has been reduced:

That being said, this readability improvement comes at the cost at doing inheritance over composability. In the future, I want to stop using metatables entirely and still keep the syntax that Seam currently has. I'm open to any ideas for this, please let me know in my OSS server!

Make sure to update Seam to get the newest changes!
